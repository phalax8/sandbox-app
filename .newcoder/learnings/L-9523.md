# No incluir claves de acceso de AWS escritas directamente en el código de src/payments

En el código TypeScript de src/payments se han colado varias veces claves de acceso de AWS (aws-access-key-id) escritas como literales en los ficheros. Si una clave queda en el repositorio, cualquiera que pueda leerlo tiene acceso a ella, y la clave sigue en el historial de git aunque después se borre del fichero. Lee las credenciales en tiempo de ejecución desde variables de entorno (`process.env`), igual que el servidor ya hace con `PORT`, o confía en la cadena de credenciales por defecto del SDK de AWS. Si se publica una clave por error, hay que revocarla y crear una nueva, no basta con borrarla del código.
