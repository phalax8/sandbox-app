# No señalar la falta de autenticación propia en las rutas /internal/* de la API Python

No reportes como problema de seguridad que las rutas `/internal/*` de la API FastAPI carezcan de autenticación propia: solo son accesibles desde la red interna y la autenticación la aplica el gateway. No cubre inyecciones, secretos ni datos sensibles expuestos.
